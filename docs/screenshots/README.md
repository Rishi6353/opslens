# OpsLens Screenshots Directory

This directory stores visual assets for portfolio presentation, documentation, and the main `README.md`.

## Recommended Screenshots

1. `dashboard.png` — Analytics Overview showing metrics cards, 7d/30d/90d filter, and Chart.js visualizations.
2. `tickets_list.png` — IT Helpdesk ticket grid with search, filter badges, and priority indicators.
3. `ticket_detail.png` — Single ticket view showing SLA timeline, comments, and status transitions.
4. `audit_log.png` — Administrator Audit Log Explorer with filter controls and actor/action timeline.
5. `security_headers.png` — DevTools Network tab showing security response headers (`X-Frame-Options`, `X-Content-Type-Options`, CSRF cookie).

## Capture Tips
- Use clean browser window dimensions (1280x800 or 1440x900).
- Ensure test data is populated using `flask seed-db` before capturing.
- Optimize image files using `pngquant` or similar tools to keep repository size lean.
